# Pauze

A lightweight landing page for Pauze, focused on a clean, responsive presentation and a minimal user experience.

## Overview

The project is a static web page with a visual waitlist form. The current form is a frontend placeholder and does not submit data to an external service.

## Run locally

No build system is required.

Open `index.html` directly in a browser, or serve the project with any static web server.
