A lightweight landing page for Pauze, focused on a clean, responsive presentation and a minimal user experience.

## Overview

The project is a static web page with a visual waitlist form. The current form is a frontend placeholder and does not submit data to an external service.

## Run locally

No build system is required.

Open `index.html` directly in a browser, or serve the project with any static web server.

## Status

This repository contains the current landing-page implementation and can be extended with a real waitlist backend when required.

## Run with Node.js

The repository also includes a small Node.js static server. With Node.js installed, run:

```bash
npm start
```

The server listens on port `3000` by default. Set the `PORT` environment variable to use another port. There are no package dependencies, build script, or test script in `package.json`.
